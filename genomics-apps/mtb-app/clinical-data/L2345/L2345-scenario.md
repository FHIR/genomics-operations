# Larry Lung (MRN L2345): clinical scenario

Synthetic patient for the MTB app clinical-data demo (see `mtb-clinical-data-design.md` in the repo root).
FHIR data: [L2345-transaction-bundle.json](L2345-transaction-bundle.json) (mCODE STU4 / US Core 6.1, transaction bundle).
The JSON is generated by [build_l2345.py](build_l2345.py), which uses the shared [mcode_helpers.py](../mcode_helpers.py). To change the data, edit the script and rerun it (`python build_l2345.py`). Don't hand-edit the JSON: the next run would overwrite those edits.

## Base scenario

> Patient Larry Lung is a 66 yo male, never smoked, presented May 10, 2023 with persistent intermittent dry cough, found to have a RLL lung mass on CXR. Chest CT and PET showed the RLL lung mass with right hilar adenopathy and additional pulmonary and bony metastases. Brain MRI with no evidence of intracranial metastases. Fine needle aspiration of the RLL lung mass showed adenocarcinoma, as did the left iliac biopsy specimen. Tumor genomic profiling has been performed.

## Elaborations added to the base scenario

These were chosen to fit the variants the genomics server holds for L2345 (see [Genomic data](#genomic-data-on-the-genomics-operations-server)). All of them can be changed.

- **Staging:** 4.3 cm RLL mass (T2b), ipsilateral hilar nodes only (N1), contralateral pulmonary nodules plus multiple bone metastases in the left ilium, T10 and right 6th rib (M1c) → **cT2b cN1 cM1c, stage IVB** (AJCC 8th edition).
- **Pathology:** TTF-1+, Napsin A+, p40−. PD-L1 TPS 5% (22C3).
- **Initial profiling (June 2023):** EGFR exon 21 L858R. No ALK, ROS1, RET or NTRK fusions; no MET exon 14 skipping; KRAS and BRAF wild type.
- **Treatment:**
  - Palliative RT to the painful left iliac metastasis, 20 Gy in 5 fractions.
  - First line: osimertinib with carboplatin/pemetrexed (the FLAURA2 regimen), followed by pemetrexed maintenance.
  - Zoledronic acid for the bone metastases.
- **Course:** partial response, then about 2.5 years of stable disease. Progression in September 2026: enlarging RLL primary, new liver metastases, and a new LLL nodule. Liver biopsy confirms adenocarcinoma with no small cell transformation, and goes for **repeat genomic profiling**. That repeat profile is what the genomics server represents. The case is now being brought to the molecular tumor board.
- **Background:** hypertension, hyperlipidemia, penicillin allergy (rash).

## Validation

HL7 FHIR validator against `hl7.fhir.us.mcode#4.0.0` with tx.fhir.org: **0 errors** (re-validated 2026-10-22). All codes were also checked one by one against tx.fhir.org (SNOMED, LOINC, ICD-10-CM) and RxNav (RxNorm).

**Text convention:** each `CodeableConcept.text` reads like its code's display. It may add site or laterality, but never interpretation or extra facts. Details such as lesion sites, TNM descriptions and the EGFR status go in `note`. (Adopted 2026-10-22, since the app shows `code.text` when present.)

The remaining warnings are all benign:
- No narrative (`text`) on resources. Narratives are a best practice only.
- The RxNorm code system version the terminology server has doesn't match the one the validator expects, so RxNorm codes can't be checked. All RxNorm codes were confirmed separately via RxNav.
- Pathology and molecular LOINC codes fall outside the US Core *Non Laboratory Codes* value set. The binding is extensible, so this is allowed.
- The CKD-EPI eGFR unit `mL/min/{1.73_m2}` contains a UCUM annotation, which is conventional for this lab.
