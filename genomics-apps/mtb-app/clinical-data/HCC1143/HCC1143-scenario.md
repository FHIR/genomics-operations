## What the literature says (real)

HCC1143 is a widely used breast cancer cell line, with a matched normal B-lymphoblastoid line (HCC1143 BL) from the same patient's blood. Gazdar et al. described both in *Int J Cancer* 1998;78:766-774 (PMID 9833771).

## Elaborations (invented, labeled)

**Confirmed by Bob 2026-10-22:** present-day dates, surgery first, the recurrence storyline, and the name.

- **Dates are moved to the present** (diagnosis 2024, tumor board 2026-10), so the case shows current care. The real tumor was collected in 1994. Age at diagnosis is kept at 52 (DOB 1972-01-18).
- **Name, laterality and site:** "Betty Breast"; right breast, upper outer quadrant (10 o'clock).
- **Diagnosis code:** SNOMED 408643008 *Infiltrating duct carcinoma of breast* (text "…of right breast"), chosen because it is in the VSAC Breast Cancer value set that sets the predictor's tumor type (design doc §5.5).
- **Stage:** clinical **cT1c cN0 cM0, stage IA** (1.9 cm on ultrasound); pathologic **pT2 pN0, stage IIA** (2.3 cm, 0 of 3 sentinel nodes). This matches the published stage IIA and follows ATCC's "no lymph node metastases". It also gives the bundle both a clinical and a pathologic stage, which tests the "more than one stage assessment" rule (design doc §4.3). Stage groups are AJCC 8th edition anatomic; a note says the prognostic stage would be higher.
- **Surgery first:** the cell line came from an untreated primary tumor, so the patient has upfront partial mastectomy and sentinel node biopsy (reasonable for a cT1c N0 tumor). Today a larger node-positive or T2 triple-negative tumor would more often get neoadjuvant chemoimmunotherapy (KEYNOTE-522).
- **Tumor genomic profiling** on the partial mastectomy specimen with matched normal: TP53 R248Q, nothing else actionable, MSS. This is the profile the genomics server holds.
- **Germline panel:** negative (consistent with the published BRCA1 wild type).
- **Adjuvant therapy:** dose-dense AC × 4 with pegfilgrastim, then weekly paclitaxel × 12; then whole-breast RT 40.05 Gy in 15 fractions.
- **Distant recurrence at about 21 months after surgery:** bilateral lung nodules and mediastinal nodes (no liver, bone or brain disease). Lung biopsy confirms triple-negative breast cancer. PD-L1 22C3 CPS 12.
- **Tumor board question (now):** first-line treatment for metastatic TNBC, with PD-L1 CPS ≥ 10, a TP53-only genomic profile and no germline BRCA mutation.
- **Background:** hypothyroidism on levothyroxine; ex-smoker; no known allergies; mother had breast cancer at 64.

## Data-shape features this bundle exercises

These differ from L2345 on purpose, to test the display rules in design doc §4.2–4.3:
- **Two stage assessments** (clinical IA, pathologic IIA) on one primary cancer.
- **Primary cancer `clinicalStatus` = recurrence**, alongside a CancerDiseaseStatus Observation.
- **Repeated tumor markers:** ER, PR and HER2 on both the 2024 breast biopsy and the 2026 lung biopsy.
- **ICD-O-3 codes:** histology 8500/3 and topography C50.4, alongside SNOMED and ICD-10-CM C50.411. Useful for the §5.5 mapping-table work.
- **A tumor-marker result with a text value** (PD-L1 CPS as a string, because LOINC has no code for CPS), and a series of CA 15-3 values (3 points, so it gets a trend line).
- **No current cancer medications:** all cancer therapy is completed. Levothyroxine is the only active medication.
- **"No known allergy"** recorded as an AllergyIntolerance.
- **A FamilyMemberHistory**, a resource type the Case summary doesn't have a section for. It should land in "Other resources".
- **A Histologic Grade Observation** (mCODE profile, NCIt code).

## Validation

HL7 FHIR validator against `hl7.fhir.us.mcode#4.0.0` with tx.fhir.org: **0 errors** (2026-10-22). All codes were also checked one by one against tx.fhir.org and RxNav.

The remaining warnings are the same benign ones as L2345 (no narrative, RxNorm version mismatch, extensible value-set notes), plus three:
- tx.fhir.org holds only part of ICD-O-3, so it can't confirm `C50.4`.
- Ki-67 isn't in mCODE's tumor-marker value set; the binding is extensible, so it's allowed.
- The histologic grade code (mCODE's own NCIt code) isn't in US Core's lab value set.

**Text convention:** as in L2345, each `CodeableConcept.text` reads like its display (laterality added for the primary cancer). Details go in `note`.
